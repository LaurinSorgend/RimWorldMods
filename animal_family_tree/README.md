# Animal Family Tree

RimWorld mod that draws family trees for your colony's animals. Supports RimWorld 1.6 and 1.7. No Harmony, no other dependencies.

## Features

- "Animal family" tab on the bottom bar. The left side lists animals with search, a species filter and an alive/dead filter. The right side shows the tree.
- "Family tree" button on any selected colony animal, which opens the tab on that animal.
- Ancestors and descendants up to a configurable number of generations, plus siblings, half-siblings, aunts and uncles, nieces and nephews, cousins, and mates (animals that share offspring).
- Each pair of parents gets its own line color and lane. Hovering an animal highlights its lines.
- Right-click an animal to locate it on the map, open its info card, or re-center the tree on it.
- Dead animals stay in the tree with a grave marker, including ones the game has already deleted.

## How lineage is kept

RimWorld stores animal parentage as `Parent` relations on the pawn. It deletes dead and off-map animals fairly quickly, and their relations go with them. The mod saves its own data instead:

- `LineageTracker` is a `GameComponent`. Once per in-game hour, and whenever the tab opens, it scans player-faction animals together with their parents and offspring.
- Each animal gets a `LineageRecord` with its load ID, name, `PawnKindDef`, gender, birth tick, death tick and parent IDs. Parent IDs are only ever added, never removed.
- The records are written to the save file. The tree is built from the records, and the live pawn is used for icons and map actions while it still exists.

Removing the mod from a save is safe. The game logs a warning about the missing component on the next load.

## Settings

Options > Mod settings > Animal Family Tree:

| Setting | Default |
|---|---|
| Generations of ancestors | 3 |
| Generations of descendants | 3 |
| Maximum animals per tree | 150 |
| Grave marker on dead animals | on |
| Keep recording animals that left the colony | on |

## Building

Requires the .NET 10 SDK. Game references come from the [Krafs.Rimworld.Ref](https://www.nuget.org/packages/Krafs.Rimworld.Ref) NuGet package, so the game does not need to be installed to build.

```
pwsh build.ps1
```

This builds `1.6/Assemblies/AnimalFamilyTree.dll` (net48) and `1.7/Assemblies/AnimalFamilyTree.dll` (net10.0). To build a single version:

```
dotnet build Source/AnimalFamilyTree.csproj -c Release -p:GameVersion=1.6
```

The 1.7 references are an unstable package version until Ludeon publishes a stable 1.7.

For local testing, link the folder into the game's `Mods` directory:

```
New-Item -ItemType Junction -Path "<RimWorld>\Mods\AnimalFamilyTree" -Target "<repo>\animal_family_tree"
```

Textures are generated by `tools/make_textures.ps1` (Windows, uses System.Drawing).

## Layout

```
About/                 mod metadata, preview and icon
Common/                defs, English strings, textures (shared by all versions)
1.6/, 1.7/             built assemblies per game version
LoadFolders.xml        maps game version to folders
Source/
  Data/                LineageRecord, LineageTracker
  Tree/                FamilyGraph, RelationNamer, TreeLayout, FamilyConnectors
  UI/                  main tab, list panel, tree canvas, node drawing, menus, legend
  Gizmo/               the "Family tree" button and the comp injector that adds it to all animal races
```

## Releases

CI builds both versions on every push and pull request that touches this folder, and uploads a zip of the mod as an artifact. Pushing a tag such as `animal-family-tree-v0.1.0` also creates a GitHub release with that zip attached.
